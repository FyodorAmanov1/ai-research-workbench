# Structured query tool

## Question

Can a user retrieve exact saved measurements and distinguish missing measurements from related experiment records, while preserving source identity, reported zeros and negative findings?

## Method

Use the existing four-project, ten-experiment registry without refreshing or changing frozen retrieval. `src/structured_query.py` adds frozen dataclass request types for project, experiment and metric queries. Exact case-sensitive selectors scope each lookup. Project queries optionally select a project; experiment queries require a project and optionally select a local experiment ID; metric queries require both identities and optionally select an exact metric label. Omitted optional selectors enumerate that scope. No natural-language parsing, fuzzy matching, unit conversion, arithmetic or model inference is used.

Dataclasses supply a typed Python interface; explicit runtime validation rejects blank strings, wrong field types, extra fields and missing required selectors. Annotations alone do not enforce runtime types; see official [dataclasses](https://docs.python.org/3.12/library/dataclasses.html) and [typing](https://docs.python.org/3.12/library/typing.html) documentation. Unknown projects, experiments and metrics have separate error codes. Unknown metric responses retain the selected source boundary and omit `data`. Zero is never substituted for missing data. Invalid source hashes, duplicate source IDs or metric labels, nonfinite or boolean values and missing units block loading. Missing registry files produce a separate unavailable-registry error.

Each loaded response includes the SHA-256 of exact registry bytes, including formatting. Each selected source carries its source ID, URL, inherited artifact hash, indexed-text hash and complete-record hash. The latter hashes Python sorted-key, ASCII-escaped JSON with compact separators and finite numbers, including metrics and metadata. This is an application serialization, not a cross-language canonicalization standard. A text-only hash cannot detect edits confined to typed metric metadata; a complete-record hash does. The registry-byte hash identifies the complete saved snapshot. These hashes identify evidence versions in the spirit of [W3C PROV-DM](https://www.w3.org/TR/prov-dm/), without claiming authenticated provenance or PROV conformance.

`experiments/AI05-queries.json` contains twelve source-aware authored regression probes. Six request known data: project enumeration, experiment enumeration, stable frozen-ridge MAE, shifted observed coverage, directional-market paired improvement and balanced-flow violations. Six request absent data: an unknown project, an unknown experiment and four missing measurements in related sources. Expected values and enumeration counts are explicit fixture constants. Both methods access the same registry. The baseline is unchanged BM25 with its existing tokenizer, positive-score filter and cutoff three, receiving an authored lexical rendering of each request. The ledger retains every rendering, selector, expected code, returned source, value and actual outcome. Exact lookup receives structured identities; BM25 promises record relevance rather than typed answers. This information asymmetry limits the comparison.

## Actual findings

| Measure | Exact structured queries | BM25 record retrieval |
| --- | ---: | ---: |
| Known requests matching specified data | 6/6 | Not a typed-output contract |
| Explicit unknown-data errors on absent requests | 6/6 | Not provided by search |
| Absent requests returning metric values | 0/6 | Not a metric-answer interface |
| Related nonempty retrieval on absent requests | No fallback | 6/6 |
| Empty retrieval on absent requests | Explicit errors instead | 0/6 |
| Probes matching query specification | 12/12 | Not applicable |

Stable frozen-ridge MAE remains **0.4030305544093381**, shifted observed coverage **18.761384335154826%**, directional-market paired improvement **-528.83125 ticks**, and balanced-flow cash/inventory violations **0**. The query preserves the negative result without inferring live performance. A requested base-market VaR confidence interval returns `unknown_metric` with source references and no value, without borrowing an interval from another experiment. An absent compiled-gate count also returns an explicit error. Lexical search retrieves related records for every absent request; nonempty retrieval is an unsupported-answer risk proxy, not a generated false statement.

The seventh studio case, **Structured query tool** at `#structured-query`, shows the measured ledger and an interactive form with editable selectors. Blank optional selectors list the scope; a demonstration button requests an absent interval. The browser verifies registry bytes against the generated study snapshot before querying and returns the same source descriptors as Python. A changed registry disables the form until regeneration. Inspectable JSON includes unrounded metric values and hashes; output is inserted as text. Existing APIs, CLI operations and frozen studies remain reproducible.

## Reproduce

```bash
python -m src.query_study --output results/AI05-queries.json
python lab.py --output results/latest.json
python src/studio.py --out docs/study.json
python src/studio.py --check docs/study.json
python -m unittest discover -s tests -v
python quality/contract.py --project . --name ai-research-workbench --task-id AI05
```

Serve `docs` using the README command and open `/#structured-query`. Python callers use `QueryTool.from_path().execute(MetricQuery("statistical-learning-lab", "stationary", "Frozen ridge MAE"))`. The CLI accepts `python -m src.structured_query --query '{"kind":"project"}'`; it prints JSON and exits 2 on errors. Python snapshot-loading failures raise `QueryError` with a stable `code`. No new dependency is required.

Tests exercise enumeration and exact lookup for all 40 saved metrics, unknown scopes, runtime type failures, duplicate and invalid evidence, finite numeric/unit boundaries, preservation of zero, result mutation isolation, metric-only hash drift, registry formatting drift, CLI status and JSON output, unavailable registries, saved-result agreement and browser/Python parity when Node is available. Earlier comparison and frozen retrieval suites remain intact.

## Limitations

These twelve authored probes are regression evidence, not an independently authored or sealed confirmation benchmark or representative user sample. Exact identities and labels must be known or discovered through enumeration. Case differences and aliases intentionally fail. Unknown means absent from this snapshot, not scientifically nonexistent. Errors do not automatically interpret source limitations or establish whether a question is answerable elsewhere.

The sources describe small synthetic studies. Hashes detect accidental drift; replacing all content and hashes can replace the record too. Artifact hashes are inherited without fetching original companion bytes. Browser source descriptors are trusted from the generated study and bound to its registry digest; they are not signatures. Python validates and owns its decoded snapshot; trusted legacy loaders retain their existing behavior. This tool performs no scientific validation or compatibility comparison; use the existing comparison gate before subtracting measurements. No external inference, latency, infrastructure price or cost advantage is measured. No real-world accuracy, live performance or quantum advantage follows.

## Interview understanding

Explain why a relevant experiment can lack a requested measurement; demonstrate the absent VaR interval beside the recorded scalar VaR. Distinguish an error from zero, a negative improvement from success, and observed coverage from a nominal target. Trace a metric through project/experiment scope, full source ID and all four hash boundaries. Explain why a text hash misses metric-only edits, why registry hashes change on formatting, and why neither proves authenticity. Explain the information asymmetry between exact selectors and lexical questions, and why these counts establish contract behavior rather than natural-language superiority. Preserve source units, context and limitations when using a returned value.
