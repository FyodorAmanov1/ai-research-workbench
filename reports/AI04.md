# Independent confirmation questions

## Applied question

Does the fixed evidence explorer still rank the requested source first on a second wave of paraphrased questions, and do better rankings prevent unsupported-topic retrieval?

BM25 finds the expected source first on 19/20 answerable questions, versus 16/20 for unique-term overlap. Both find all 20 within the first three results. Both also return evidence for all four unsupported requests with overlapping vocabulary. The ranking difference does not solve the absent-measurement problem.

## Method

The earlier 30-question confirmation study remains reproducible and unchanged. Before authoring this new wave, `experiments/AI04-freeze.json` fixed the complete ten-record registry, Python and browser retrieval implementations, existing baseline and summary code, new evaluator, earlier question file, rules, cutoffs, metric definitions and question counts. This additionally freezes the code that computes the evaluation. After all 28 new questions, labels and rationales were authored, `experiments/AI04-seal.json` recorded the manifest and question-file SHA-256 values before either method ran on them. Neither rules nor questions nor labels changed after evaluation. Validation rejects drift rather than silently substituting a new study. The sequence is a local research record; hashes do not establish an external timestamp or prevent replacement of the entire record.

The new set has two answerable questions per source, four unrelated unsupported questions and four unsupported requests using collection vocabulary. It includes paraphrases such as “one-sided” for the directional market and “fixed regressor” for frozen ridge. Answerable labels carry exact excerpts from the frozen evidence text; the evaluator checks those excerpts. These anchors make label reasoning inspectable, without automatically proving that the interpretation is correct. Unsupported labels explain the missing measurement or evidence boundary. Duplicate questions from the earlier confirmation set are rejected, and tests also check novelty against the studio regression questions.

BM25 retains the existing title-plus-text fields, ASCII tokenization, stopwords, unique query terms, k1=1.2, b=0.75, positive-score filtering and source-ID tie break. The baseline counts unique matching query/document terms on the same fields with the same tokenizer, filter and ties. Both return at most three records and are measured at cutoffs 1 and 3; no setting is selected from these outcomes. The algorithmic reference remains [Robertson and Zaragoza (2009), BM25 and Beyond](https://doi.org/10.1561/1500000019) (publisher record and author-hosted text verified). The exact comparator and evaluation definitions are application choices specified in the freeze manifest.

Source recall uses only the 20 answerable questions. At each cutoff its misses are partitioned into nonempty retrieval containing no expected source and empty retrieval: hits + wrong-source misses + empty misses = 20. The unsupported false support proxy uses only the eight unsupported questions and means any returned record. It is reported separately from empty unsupported retrieval: false support + empty unsupported retrieval = 8. A related record that explicitly states a limitation can be useful, but does not supply an absent requested measurement. No generated-answer error or semantic entailment score is measured.

## Actual findings

| Measure | Frozen BM25 | Unique-term overlap |
| --- | ---: | ---: |
| Source recall at 1, answerable only | 19/20 (95%) | 16/20 (80%) |
| Source recall at 3, answerable only | 20/20 (100%) | 20/20 (100%) |
| Source misses at 1 | 1/20 | 4/20 |
| Nonempty wrong-source misses at 1 | 1/20 | 4/20 |
| Empty answerable retrieval | 0/20 | 0/20 |
| Source misses at 3 | 0/20 | 0/20 |
| Unsupported false support proxy | 4/8 (50%) | 4/8 (50%) |
| False support on misleading overlap | 4/4 | 4/4 |
| False support on unrelated topics | 0/4 | 0/4 |
| Empty unsupported retrieval | 4/8 | 4/8 |

For i13 (“When order flow is one-sided…”), both methods rank informed flow first, balanced flow second and directional market third. They retrieve plausible neighbouring experiments but fail to resolve the case paraphrase at rank 1. BM25's own miss is preserved. The baseline also ranks the quantum oracle above asset allocation for i07, and the regime-break source above the stable case for i17 and i18. The expected source is second in those three baseline cases. Source rank, rather than an outcome at cutoff 3 alone, exposes these failures.

Both methods retrieve records for absent base-market VaR confidence intervals, compiled allocation gate counts, calibrated exchange auction rules and molecular geometry/basis sets for the effective electron model. All four unrelated questions return nothing. Thus the aggregate 50% unsupported proxy depends on this authored mixture; it is not a deployment error rate. Compared with the earlier wave's 60%, the difference reflects different questions and stratum counts, not a retrieval improvement. Earlier negative scientific findings remain untouched.

The studio adds **Independent confirmation questions** at `#independent-confirmation`. It shows separate recall, miss and unsupported-outcome charts, both ranked source lists, expected-source ranks, source anchors, rationales and CSV export. The full result is `results/AI04-confirmation.json` and is included in `results/latest.json`. The original five studio cases, public APIs and CLI remain available. No new runtime dependency is introduced.

## Limitations

Questions were source-aware and earlier outcomes were visible. Independence means a fresh question wave without retrieval parameter selection on it, not an independent human author, blinded annotation or representative sampling. Paraphrase-to-case labels involve judgement. Exact excerpts verify that text exists, not that every label is semantically unambiguous. The small rank-1 difference establishes neither statistical superiority nor real-world accuracy. No generated answer correctness is assessed.

The registry describes small synthetic experiments; this study measures retrieval over their saved reports, not scientific validity, live trading performance, hardware performance or scalability. No API, LLM, runtime benchmark or infrastructure price is involved. Both methods access the same evidence; no operation-count or cost advantage is claimed. Hashes expose drift relative to saved manifests but are not authenticated provenance. Subsequent retrieval changes require a new protocol and fresh questions rather than tuning these sealed outcomes.

Trace i13 through both rankings and distinguish a rank-1 miss from an empty search and from a source recovered at rank 3. Use the absent VaR interval question to explain why a relevant limitation is not the requested measurement. Derive both accounting identities and denominators; never add correct abstentions to source recall. Explain why source-aware authored confirmation is useful regression evidence but insufficient for population accuracy, and why changing the unsupported-question mix changes its aggregate rate without changing the system.
