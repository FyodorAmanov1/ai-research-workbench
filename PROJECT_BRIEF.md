# Flagship direction

Build an evidence-driven AI research interface around actual experiment artifacts, with inspectable provenance and bounded integration.

Read src/studio.py, docs/study.json and reports/applied-study.md before adding features. Extend the applied application and its usable interface. Preserve legacy public APIs.

## Next priorities

- Freeze retrieval rules, then author independent confirmation questions and report false support separately from empty retrieval.
- Add compatible experiment comparisons that reject unit, dataset and protocol mismatches.
- Add explicit registry refresh and stale-artifact diagnostics while retaining source IDs and full evidence boundaries.

Every milestone must answer a substantive applied question, compare a meaningful baseline, measure actual results and expose the result in the existing studio when relevant. Avoid isolated textbook scripts. Preserve negative findings. Keep artifacts compact and dependencies pinned; no API keys, extra agents or model sessions.
